# Local Delivery Assignment System

A serverless delivery management application built using AWS and DevOps tools.

## Project Objective

To help small businesses create delivery jobs, assign available drivers, and monitor delivery status.

## Technology Stack

- AWS Lambda – Backend processing
- Amazon API Gateway – REST API
- Amazon DynamoDB – Database
- Amazon S3 – Frontend hosting
- Amazon CloudFront – Content delivery
- Amazon SNS – Notifications
- Amazon CloudWatch – Monitoring
- Python – Backend programming
- Terraform – Infrastructure as Code
- GitHub Actions – CI/CD

## Main Features

1. Delivery job creation
2. Driver registration
3. Driver assignment
4. Delivery status updates
5. Delivery monitoring dashboard
6. Automated deployment

## Architecture

Serverless AWS Architecture
